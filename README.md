## Giới thiệu
Hồng Anh Eyeshop là một nền tảng thương mại điện tử chuyên về kính mắt
Hệ thống hỗ trợ đầy đủ các tính năng của một website bán hàng từ quản lý sản phẩm, danh mục, đa biến thể (variants), tồn kho, đến giỏ hàng, thanh toán và hệ thống SEO/Filter linh hoạt.

> Demo: https://honganh-eyeshop.vercel.app/
## Architecture
- System architecture: monolith
- Application architecture: vertical slice architecture


## Tech stack

- Fullstack Framework: Next.js 15 + TypeScript
- DBMS: MongoDb + mongoose
- UI: Tailwind CSS, Tiptap Editor, Recharts, Shadcn/ui, Zustand, TanStack React Query, React Hook Form + Zod, Embla Carousel
- Search engine: Typesense


## Chức năng
- Authentication hỗ trợ đăng nhập với google
- Tìm kiếm, lọc sản phẩm
- Review sản phẩm
- Giỏ hàng
- CRUD sản phẩm, loại hàng, blog, mã giảm giá, quản lý đơn hàng(admin dashboard)
